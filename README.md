# 固件文件工具箱

这是一个纯前端 PWA，集成最新 V55 双文件参数对比、主转换工具和行校验工具。文件只在浏览器本地处理，不上传服务器。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

手机与电脑处于同一个局域网时，可以使用终端显示的局域网地址访问。正式部署必须使用 HTTPS，才能稳定安装为 PWA。

## 验证

```powershell
npm.cmd run test:core
npm.cmd run build
```

构建结果在 `dist` 目录，可部署到任意静态网站托管服务。部署时不要设置 ZIP 下载拦截；运行器标准库使用 `.data` 扩展名，以兼容会拦截 ZIP 请求的浏览器环境。

## 已支持

- 主转换工具：打开 HEX、BIN、S19、S28、S37、MOT、SREC，自动识别设备家族、修改字节、重算总校验、导出 HEX 或 BIN。
- 行校验工具：打开 HEX、BIN、S19、S28、S37、MOT，修改字节、搜索、跳转并导出多种记录格式。
- V55 参数对比：同时打开两个固件，按地址对齐查看差异，支持双侧编辑、同步跳转、差异导航、校验重算和导出。
- 手机分页编辑、地址跳转、十六进制搜索、ASCII 联动输入。
- 首次在线加载完成后离线使用。
